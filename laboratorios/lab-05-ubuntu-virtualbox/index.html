Laboratorio 5: Instalar Ubuntu en VirtualBox

Guía paso a paso para crear una máquina virtual con Ubuntu Server 24.04 LTS en VirtualBox, conectar por SSH y dejarla lista para los laboratorios de la Unidad 3. Adaptador puente para acceso remoto desde el aula.

👨‍🏫 Docente: Ing. Rodolfo Cañas Cervantes 🏛️ Universidad de la Costa (CUC) 📅 Semana 12 · Formativa · ~90 min · 2026-2

En este laboratorio instalarás Ubuntu Server 24.04 LTS en una máquina virtual de VirtualBox y la configurarás para que sea accesible desde tu PC anfitrión mediante SSH. La VM quedará lista para los laboratorios de la Unidad 3, donde trabajarás con herramientas de seguridad de redes sobre este mismo entorno.

Actividad formativa: no suma nota, pero es requisito para continuar con la Unidad 3. Tiempo estimado: ~90 minutos. Individual.
Importante: los pantallazos de este documento son capturas reales ejecutadas en el entorno de laboratorio o marcadores [CAPTURA PENDIENTE: …] cuando aún no se dispone de la captura real.
1

Requisitos y verificación previa

Antes de instalar, verifica que el PC del aula cumpla los requisitos para ejecutar VirtualBox y una máquina virtual con Ubuntu Server.

Checklist de requisitos

  • VirtualBox instalado: versión 7.x o superior, disponible en virtualbox.org.
  • Virtualización habilitada en BIOS/UEFI: VT-x (Intel) o AMD-V (AMD) activo.
  • RAM disponible: mínimo 4 GB libres para asignar 2–4 GB a la VM.
  • Disco disponible: mínimo 30 GB libres para el disco dinámico de 25 GB de la VM.
  • ISO de Ubuntu Server 24.04 LTS: descargar desde ubuntu.com/download/server.

Descarga y verificación de la ISO

Descarga la imagen ISO de Ubuntu Server 24.04 LTS y verifica su integridad con SHA-256 antes de usarla.

# PowerShell (Windows)
Get-FileHash -Algorithm SHA256 ruta-al-archivo/ubuntu-24.04-live-server-amd64.iso

# certutil (Windows)
certutil -hashfile ruta-al-archivo/ubuntu-24.04-live-server-amd64.iso SHA256

# Linux/macOS
sha256sum ubuntu-24.04-live-server-amd64.iso

Compara el hash resultante con el publicado en la página de descarga de Ubuntu. Si no coinciden, no uses esa ISO.

¿Por qué adaptador puente?

El adaptador puente conecta la VM directamente a la red física del aula. La VM obtiene su propia dirección IP del servidor DHCP de la red, es visible como cualquier otro equipo y permite conexiones SSH desde el PC anfitrión. Si el puente no obtiene IP, usa NAT como alternativa (pero entonces no habrá acceso remoto).

3

Instalación de Ubuntu Server paso a paso

Inicia la VM con la ISO montada y sigue el instalador de Ubuntu Server.

Pasos de la instalación

  1. Idioma y teclado: selecciona español (España o Latinoamérica) y teclado español.
  2. Red: con adaptador puente, el instalador obtendrá una IP por DHCP automáticamente.
  3. Disco: elige "Usar un disco completo" y selecciona el disco virtual de 25 GB.
  4. Usuario: crea tu usuario y contraseña. Anótalos.
  5. OpenSSH server: marca sí para instalar el servidor SSH (necesario para acceso remoto).
  6. Snaps extras: no instales snaps adicionales (opcional).
  7. Finalizar: el instalador reiniciará la VM. Retira la ISO de la unidad virtual.
[CAPTURA PENDIENTE: pantallazo de la pantalla de selección de "OpenSSH server" durante la instalación de Ubuntu Server]
Importante: no instales el entorno de escritorio (GUI) a menos que sea necesario. Ubuntu Server sin GUI consume menos recursos y es más seguro.
4

Primer arranque y configuración inicial

Tras la instalación, inicia la VM y verifica que la red funciona correctamente.

Verificar la dirección IP

$ ip -br a
lo               UNKNOWN        127.0.0.1/8
enp0s3           UP             192.168.1.XX/24

La dirección IP de la interfaz de red (enp0s3, eth0 o similar) es la que usarás para conectarte por SSH. Anótala.

Verificar conectividad

$ ping -c 3 1.1.1.1
$ ping -c 3 192.168.1.1   # puerta de enlace del aula (ajusta según tu red)

Actualizar el sistema

$ sudo apt update && sudo apt upgrade -y

Configurar el nombre del equipo

$ sudo hostnamectl set-hostname ubuntu-s12

Crear usuario adicional (opcional)

$ sudo adduser estudiante
$ sudo usermod -aG sudo estudiante
[CAPTURA PENDIENTE: pantallazo del comando ip a mostrando la IP obtenida por el adaptador puente]
5

Conexión por SSH desde el PC anfitrión

Desde PowerShell o el símbolo del sistema de tu PC anfitrión, conéctate a la VM mediante SSH usando la IP obtenida en el paso anterior.

Comando SSH

ssh tuusuario@192.168.1.XX

Reemplaza tuusuario por el nombre de usuario que creaste durante la instalación y 192.168.1.XX por la IP real de tu VM.

[CAPTURA PENDIENTE: pantallazo de la conexión SSH desde PowerShell a la VM de Ubuntu]
Si SSH no conecta: verifica que OpenSSH server se instaló durante la instalación de Ubuntu, que la IP es correcta y que el adaptador puente obtuvo una dirección IP válida.

Acceso moderno por navegador (Escritorio Web noVNC)

A partir de la Semana 13, la VM cuenta con un entorno de escritorio ligero (XFCE) accesible directamente desde cualquier navegador web sin instalar clientes VNC adicionales. Ejecuta una sola vez en la consola de la VM:

curl -fsSL https://asur-col.github.io/cuc-seguridad-redes/laboratorios/entorno/instalar-entorno.sh | bash

Una vez finalizado:

  • Adaptador Puente (recomendado en aula): abre en tu navegador http://<IP-de-tu-VM>:6080/vnc.html
  • Modo NAT (si la red bloquea puente): configura reenvío de puertos en VirtualBox (Anfitrión 6080 → Invitado 6080) y accede a http://127.0.0.1:6080/vnc.html
  • Contraseña de acceso: se genera de forma única por VM y se muestra en la pantalla de inicio o ejecutando cat ~/.vnc/clave.txt
  • SSH como respaldo: la conexión SSH tradicional se mantiene 100% activa como canal de administración y soporte.
6

Instalar Docker y dejar la VM lista para la U3

Instala Docker en la VM para desplegar herramientas de seguridad en contenedores durante los laboratorios de la Unidad 3.

Instalación de Docker

$ sudo apt install docker.io -y
$ sudo usermod -aG docker $USER
$ newgrp docker

Cierra sesión y vuelve a entrar (o reinicia la VM) para que el cambio de grupo surta efecto.

Verificar Docker

$ docker run hello-world

Si ves el mensaje "Hello from Docker!", la instalación es correcta. La VM está lista para los labs de la Unidad 3.

Glosario

  • VM (máquina virtual): emulación de una computadora completa que se ejecuta como un proceso sobre el SO anfitrión.
  • Hipervisor tipo 2: software de virtualización que se instala sobre un sistema operativo existente (VirtualBox es tipo 2).
  • Adaptador puente: modo de red de VirtualBox donde la VM obtiene su propia IP en la red física y es visible como cualquier otro equipo.
  • ISO: imagen de disco que contiene el instalador de un sistema operativo.
  • SSH: protocolo de acceso remoto seguro y cifrado.
  • Docker: plataforma para crear y ejecutar contenedores, más ligeros que las VM.
  • Contenedor: instancia aislada de una aplicación que comparte el kernel del host.
  • DHCP: protocolo que asigna direcciones IP automáticamente en una red.
  • FQDN: nombre de dominio completo que identifica un equipo en la red.
